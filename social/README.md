# פרסום אוטומטי לאינסטגרם

התור יושב כאן. GitHub Actions מצלצל לאתר כל שעה, האתר בודק אם הגיע זמן של פוסט, ואם כן שולח לך אותו לטלגרם עם כפתור. הפוסט עולה רק אחרי שאתה לוחץ.

## מה עובר כאן ומה לא

**קרוסלות בלבד.** רילז וטיקטוק עולים ידנית מהאפליקציה, וזו החלטה ולא מגבלה: פוסט שעולה דרך ה-API לא יכול להשתמש בספריית המוזיקה של אינסטגרם ולא בטקסט הנייטיב. הכל חייב להיות צרוב מראש בקובץ, ואודיו טרנדי הוא אות הפצה שלא כדאי לוותר עליו. לקרוסלה סטטית אין אודיו ואין טקסט נייטיב, ולכן היא לא מפסידה כלום מהמסלול האוטומטי.

## איך מוסיפים פוסט

1. שים את קבצי השקופיות ב-`social/media/`.
2. צור קובץ חדש ב-`social/queue/`, למשל `2026-08-20-mehirim.json`:

```json
{
  "id": "2026-08-20-mehirim",
  "publishAt": "2026-08-20T19:30:00+03:00",
  "type": "carousel",
  "media": [
    "https://luminavisual.co.il/social/media/2026-08-20-mehirim-1.jpg",
    "https://luminavisual.co.il/social/media/2026-08-20-mehirim-2.jpg",
    "https://luminavisual.co.il/social/media/2026-08-20-mehirim-3.jpg"
  ],
  "caption": "הכיתוב המלא כאן.\n\nכולל האשטגים בסוף."
}
```

3. הוסף את שם הקובץ לרשימה ב-`social/queue/index.json`.
4. דחוף ל-`main`. Vercel מדפלוי, והפוסט נכנס לתור.

`publishAt` חייב לכלול אזור זמן — `+03:00` בשעון קיץ, `+02:00` בחורף.

### סוגי פוסט

| `type` | `media` | הערה |
|---|---|---|
| `carousel` | מערך של 2 עד 10 כתובות | זה מה שאתה משתמש בו |
| `image` | כתובת אחת | תמונה בודדת |
| `reel` | כתובת אחת ל-`.mp4` | ברירת המחדל אם לא כתבת `type`, אבל רילז עולים ידנית |

בקרוסלה הכיתוב יושב על הפוסט כולו, לא על שקופית בודדת. סדר השקופיות בפיד הוא הסדר שבמערך. שקופית שהיא `.mp4` מזוהה לפי הסיומת ומטופלת כווידאו בתוך הקרוסלה.

## מה צריך להגדיר פעם אחת

השלבים האלה נעשים בממשקים של מטא, טלגרם ו-Vercel. אני לא יכול לעשות אותם בשבילך — הם דורשים כניסה לחשבונות שלך.

### 1. אינסטגרם

חשבון `@luminavisual.il` צריך להיות **חשבון מקצועי** — Business או Creator. זה נעשה מתוך אפליקציית אינסטגרם: הגדרות → סוג חשבון → מעבר לחשבון מקצועי.

עמוד פייסבוק **לא** נדרש. אנחנו משתמשים במסלול Instagram Login, שמדבר ישירות מול אינסטגרם.

### 2. אפליקציית מטא

ב-`developers.facebook.com`:

1. Create App, ובבחירת הסוג בחר **Business**.
2. באפליקציה שנוצרה, הוסף את המוצר **Instagram** ובחר **API setup with Instagram login**.
3. שם תראה את החשבון שלך וכפתור **Generate token**. לחץ, התחבר עם `@luminavisual.il`, ואשר את ההרשאות `instagram_business_basic` ו-`instagram_business_content_publish`.
4. העתק את הטוקן. זה ה-**IG_ACCESS_TOKEN**.

**אין צורך ב-App Review** כדי לפרסם לחשבון שלך עצמך. אישור נדרש רק כדי לפרסם לחשבונות של אחרים.

### 2ב. שליפת מזהה החשבון

עם הטוקן ביד, הרץ את זה בטרמינל. החלף את `<TOKEN>` בטוקן שהעתקת:

```bash
curl -H "Authorization: Bearer <TOKEN>" "https://graph.instagram.com/v25.0/me?fields=user_id,username"
```

התשובה תיראה כך:

```json
{"user_id":"17841400000000000","username":"luminavisual.il"}
```

הערך של `user_id` הוא ה-**IG_USER_ID**. ודא ש-`username` באמת `luminavisual.il` — אם לא, התחברת עם החשבון הלא נכון.

### 3. משתני סביבה ב-Vercel

בממשק Vercel, תחת Settings → Environment Variables:

| שם | מה זה |
|---|---|
| `IG_USER_ID` | מהשלב הקודם |
| `IG_ACCESS_TOKEN` | מהשלב הקודם |
| `CRON_SECRET` | מחרוזת אקראית שאתה ממציא. מגנה על נקודת הקצה מפני זרים |
| `TELEGRAM_WEBHOOK_SECRET` | מחרוזת אקראית נוספת. מוודאת שההודעות באמת מטלגרם |

`TELEGRAM_BOT_TOKEN` ו-`TELEGRAM_CHAT_ID` כבר מוגדרים אצלך מטופס הלידים.

אחרי הוספת משתנים צריך **Redeploy** — הם נצרבים בזמן הבנייה.

### 4. סוד ב-GitHub

ב-Settings → Secrets and variables → Actions, הוסף `CRON_SECRET` **עם אותו ערך בדיוק** ששמת ב-Vercel.

### 5. חיבור ה-webhook של טלגרם

פעם אחת, מהטרמינל. החלף את שני הערכים בסוגריים:

```bash
curl -X POST "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook" -d "url=https://luminavisual.co.il/api/social-approve" -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```

זה מה שמחבר את כפתורי האישור לאתר.

## דברים שכדאי לדעת

**הטוקן של אינסטגרם פג אחרי 60 יום.** זו לא תקלה, זו התנהגות של מטא. כשהפרסום ייכשל פתאום עם שגיאת הרשאה — זו הסיבה. חוזרים ל-Generate token באפליקציית מטא, מנפיקים חדש, ומעדכנים ב-Vercel (כולל Redeploy).

**מגבלת קצב: 100 פוסטים ב-24 שעות.** לא רלוונטי לקצב שלך, אבל שיהיה ידוע.

**התור גלוי לציבור.** הקבצים ב-`social/queue/` מוגשים על ידי Vercel, כלומר כל אחד יכול לקרוא את הפוסטים שתכננת לפני שהם עולים. הכיתובים ממילא נועדו להיות פומביים, אבל אל תשים שם מחירים או מידע שלא רוצים שיראו מוקדם.

**"דלג" לא מוחק.** לחיצה על דלג רק מדלגת על הסבב הנוכחי. כדי שפוסט יפסיק לחזור, הסר אותו מ-`index.json`.

**הגנה מפני פרסום כפול.** לפני כל פרסום המערכת שולפת את 25 הפוסטים האחרונים מאינסטגרם ומשווה כיתובים. אם הכיתוב כבר קיים — היא לא מפרסמת שוב. לכן אל תשתמש באותו כיתוב בדיוק לשני פוסטים שונים.

**GitHub משבית תזמונים בריפו רדום.** אם לא תהיה פעילות בריפו 60 יום, GitHub יכבה את ה-workflow ותצטרך להפעיל אותו ידנית מלשונית Actions.
