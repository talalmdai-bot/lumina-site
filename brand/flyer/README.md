# LUMINA · פלייר שיווקי

## קבצי מקור
- `final.html` — הפלייר האנכי (1080x1920). זהו קובץ המקור, כל השינויים נעשים כאן.
- `square.html` — הגרסה המרובעת לאינסטגרם (1080x1080).
- `assets.py` — כל התמונות מקודדות ב-base64 (רקעים, פריימים מהעולמות, QR).

## איך מייצרים מחדש
דורש Node עם puppeteer-core וכרום.
- `node shot8k.js` → מייצר `flyer-8k.png` באיכות 4320x7680
- `node shotsq.js` → מייצר `square-8k.png` באיכות 4320x4320

## מה עדיין צריך עדכון
1. **מספר וואטסאפ** — כרגע placeholder `000 000 0000`. מופיע ב-final.html וב-square.html.
2. **QR** — מצביע ל-https://luminavisual.co.il. לוודא שהדומיין פעיל.

## החלטות עיצוב
- פונטים: Syncopate (לוגו וכתובת), Rubik (עברית), Frank Ruhl Libre (בס"ד). כולם ברישיון OFL, מותר לשימוש מסחרי ולהדפסה.
- רקע: רינדור הבמה עם מסך ה-LED, בשלוש שכבות עומק (רחוק מטושטש, אמצעי חד, קדמי חלקי) ליצירת תלת ממד.
- "מספר תאריכים מוגבל" הוסר במכוון — לא אמין למוצר דיגיטלי.
- הגלריה הוחלפה בשלוש רצועות צרות כדי לשמור סקרנות ולהניע כניסה לאתר.
